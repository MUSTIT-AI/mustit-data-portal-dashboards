매칭 정의: 머스트잇 Open API(/catalogs/matched-items)가 실시간 계산하는 matchedItemCount(카탈로그당 매칭 상품 수)가 2개 이상이면 매칭, 1개 이하(자기 자신뿐 또는 카탈로그 미배정)면 미매칭. ① DB 파트(신규등록 추이·판매자별 현황)는 Open API 상품 목록(/products?queryType=CREATED)으로 가져온 신규 등록 상품을 위 기준으로 판정해 catalog-matching-sync Edge Function이 주기적으로 집계·적재한 값입니다(근사치 아님, 실측값). 최신 동기화 시각은 판매자 테이블에서 확인. ② 앰플리튜드 파트는 PDP(상품상세) 조회 이벤트의 가격비교 매칭 상품 수(count_price_comparison≥2)로 판정하며, 조회(uniques) 기준 추이로 근사한 것입니다(Amplitude 원본 대시보드의 상품 고유수 수식은 이 프록시로 재현 불가). 카탈로그 등록 처리자(관리자/AI/자동동기화) 구분은 Open API 응답에 없어 제외되었습니다.
