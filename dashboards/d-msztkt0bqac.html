아직 안 불러옴 — 세그먼트 미리보기 전에 먼저 기간을 지정해 불러와주세요.

⚠ 서버 집계 함수(dash_customer_segment_preview)가 아직 배포되지 않아, 임시로 주문 원본을 이 브라우저로 직접 받아 회원번호별로 묶는 방식을 씁니다. 기간을 나눠 순차 조회해서 다소 시간이 걸리고, 원본 전체 컬럼(dash_raw_all)을 쓰기 때문에 개인정보 열람 권한이 있는 계정만 사용할 수 있습니다. 이미 불러온 기간과 겹치는 부분은 다시 불러오지 않습니다 — 기간을 늘려서 다시 누르면 새로 추가된 구간만 조회합니다. 서버 함수가 배포되면 자동으로 그쪽을 우선 사용하도록 바뀔 예정입니다.

주문 데이터 기준 고객 속성으로 AND/OR 조건을 조합해 세그먼트를 만듭니다 · 개인 식별정보(회원번호 등)는 화면에 노출되지 않고 집계 수치만 계산됩니다.

⚠ 서버에 세그먼트 집계 함수(dash_customer_segment_preview)가 아직 배포되지 않아 미리보기가 안 됩니다 — 위 "전체 고객 데이터 불러오기"를 먼저 실행하거나, 관리자가 SQL 마이그레이션을 실행해주세요.

세그먼트 이름·조건은 서버에 저장되어 모든 로그인 사용자에게 공유되고 새로고침해도 유지됩니다(수정·삭제는 만든 사람과 관리자만 가능) · 다만 위에서 불러온 고객 데이터(브라우저 집계)는 아직 이 브라우저에만 있어 새로고침하면 다시 불러와야 합니다.
